## 本轮修改

### 用户中心五期

- 同时具备用户中心访问、销售中心访问、分配与掉库设置操作权限的启用成员，可调整当前 CC。用户是否付费不再限制转交；业务线权限、目标承接资格、原负责人并发校验继续保留。
- 注册日期范围筛选包含开始日和结束日，按与列表显示相同的用户国家时区计算；查询和导出使用同一结果集。
- 所选且有权限的业务线中有启用 CC 时，显示 CC 下拉筛选；使用普通单选下拉，姓名 (邮箱)，支持搜索、清空，无额外分组。切换业务线时清除不再适用的 CC。
- CC 每次添加会员时长最多 3 个整数天；非 CC 沿用 365 天上限。未到期从当前到期日续加，已到期从当前时间续加。保存时再次校验最新 CC 标记、天数、权限和业务线；记录修改历史。

### 销售中心五期

- 时间筛选合并为“时间类型＋时间范围”：注册、最后跟进、销售预约、预约外呼。默认最后跟进且不限日期；提供今天、近 7 天、近 30 天快捷项。选择预约类型即限定有有效对应记录的用户，并展示范围提示；外呼支持已到时间、未来 24 小时快捷条件。保留独立“无销售预约”条件，可与注册、跟进、外呼时间组合。切换类型清空日期及外呼快捷条件；选销售预约时清除“无销售预约”，勾选“无销售预约”时从销售预约时间回到最后跟进时间，避免冲突。重置、分页、批量选择及导出同步筛选结果。
- 按评审反馈增加“用户状态”多选筛选，移除五期“用户类型”筛选，与列表状态口径一致；支持清空、重置，筛选后回到第一页，导出同步当前结果。

- “更多”菜单增加“添加会员时长”，沿用更新跟进操作权限，与用户中心共用表单及保存校验，CC 每次最多 3 天。
- “我的跟进”独立显示销售预约时间及预约时区；改期后显示新预约，取消的预约不作为当前预约。日期按预约自身时区的日历日期，含两端。销售预约不等同于落地页预约外呼。
- 阶段名称、原因、说明和确认提示适配当前可切换的中文、英文、韩文；保存前再次校验预约历史与原因匹配。
- 新增 Rejected、Closed 分开的阶段、原因选择、列表原因和阶段筛选；按评审反馈不提供单独的跟进原因筛选。历史阶段不擅自转为新类别。
- Rejected（已拒绝）：从未有过销售预约时才提供，包括家长拒绝接听电话；新增 Parent declined the call，保留业务截图原有 5 项：Wrong number、No demand、Call back later、Under 4 years old、Above 13/Adults。
- Closed（已关闭）：有过销售预约后才提供，不再提供 Rejected；取消预约、改期、未出勤或完成咨询后仍属于预约后阶段。原因按截图保留 11 项：Course is unsuitable to kids、Kids don't like、Parent's don't like、High fee、Device、Payment method、Not trust branding、App bug/lagging、Window demands、Just want to take the trial class、Others。Others 需补充说明。
- 用户已确认：保留原型已有销售预约、出席和咨询流程；不增加必须完成 App 试听课才能 Closed 的限制。Rejected／Closed 后可重新激活，历史记录和预约保留。
- Call pending、outbound、unreached、answered 等原有通话事实保持现有口径；不会把 Total outbound called 这种累计指标强塞成互斥跟进阶段。
- “Window demands”原文含义不够明确，英文原样保留，中文暂译为“观望需求”，评审时可确认术语。

### 系统配置五期

- 新入口 /system-v5；沿用现有角色权限、成员账号、操作日志布局和系统权限。
- 用户已确认：在成员账号标记“是否为一线销售（CC）”，角色继续负责权限。复用已有 isSalesMember 字段，不另造身份字段。
- 标记会影响 CC 筛选、承接名单和会员 3 天限制；本身不会授予页面或操作权限。成员列表显示 CC 标记，同一角色可同时包含 CC 与非 CC。
- 修复成员编辑弹窗首次打开未回填已有字段的问题，避免修改 CC 标记时重新填写账号资料。

## 订单中心五期：已有内容核对，本轮未修改

对照同仓库三期订单中心和 GitHub 当前已发布五期代码：

| 方面 | 五期已有变化 |
| --- | --- |
| 搜索 | 在订单号、用户 ID、优惠码之外，支持用户姓名与登录账号 |
| 筛选 | 新增商品、当前 CC、币种；保留业务线、国家、订单状态、支付方式 |
| 时间筛选 | 支付时间／订单创建时间／有效期到期时间三种口径；日期范围及今天、近 7 天、近 30 天快捷项 |
| 列表 | 增加当前 CC、订单创建时间；订单状态由状态代码改为中文名称 |
| 汇总 | 当前筛选订单笔数、已支付订单实付金额，按币种分别汇总 |
| 筛选反馈 | 更多筛选、已选条件标签、单项清除、重置、筛选后返回第一页 |
| 导出 | 导出当前筛选结果，并包含当前 CC、创建时间；时间统一 UTC+08:00 |
| 已取消 | 该发布版本已移除五期用户类型和金额范围筛选，用户类型列仍保留 |

需明确的现有口径：

1. 当前 CC 取用户当前 salesOwner（缺失时回退 ccName），不是订单支付时的业绩归属快照。
2. “订单创建时间”当前用交易记录中的最早时间推算，不是独立的订单创建字段。数据缺失时显示空值。
3. 时间显示和日期过滤统一 UTC+08:00；旧版按用户国家显示。
4. 没有新增支付、退款、订单生成或订单详情业务流程；仍复用原有详情组件。
